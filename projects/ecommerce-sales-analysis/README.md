# E-Commerce Sales Performance | Python Data Analysis

**Status:** In progress · **Tools:** Python, pandas, Matplotlib, Seaborn, Jupyter

## Project overview

A concise, visualization-led analysis of e-commerce sales and business performance. The objective is to identify patterns that help explain commercial performance and offer defensible, data-based recommendations.

## Data

- **Source:** [E-Commerce Sales Dataset on Kaggle](https://www.kaggle.com/datasets/thedevastator/unlock-profits-with-e-commerce-sales-data) (publisher: The Devastator; underlying data should be credited according to the Kaggle listing)
- **Download:** Save the original downloaded CSV/Excel file(s) inside `data/`. The data files are excluded from Git by `.gitignore`.
- **Selection:** If the download contains several files, set `DATA_FILE` in `analysis.ipynb` to the one you intend to analyse.
- **Coverage and limitations:** Document after inspecting the actual file(s).

## Research questions

1. How does sales performance vary across available dimensions (time, channels, products, regions)?
2. Which segments account for the largest shares of sales, and how concentrated are they?
3. Which observed differences could guide better commercial decisions?
4. What limitations prevent causal or profitability claims?

These are prospective questions: each depends on what is actually present in the dataset.

## Outputs

- [`analysis.ipynb`](analysis.ipynb): reproducible data audit, EDA, and first visualisations
- [`figures/`](figures/): saved charts, ready to embed in reports
- [`report.md`](report.md): short report template, to be completed **after** the analysis

## Run locally

Open `analysis.ipynb` in VS Code and select your Python/Jupyter kernel. If necessary, install the requirements:

```powershell
python -m pip install -r requirements.txt
```

Download the Kaggle dataset into `data/`, then run the notebook cells. Confirm data definitions and units before publishing any findings.

## Reproducibility

The original raw data is not included. Download from the linked source and keep the same files in `data/`. Figures should be regenerated by running the notebook.
